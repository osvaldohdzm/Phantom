# Phantom Cloud Deployment

This folder is reserved for cloud-specific infrastructure automation definitions.

## Subdirectories

- `aws/`: Configurations for Amazon Web Services (Fargate/EKS, RDS, ElastiCache).
- `gcp/`: Configurations for Google Cloud Platform (GKE, Cloud SQL, Memorystore).
- `azure/`: Configurations for Microsoft Azure (AKS, Azure Database, Redis).
