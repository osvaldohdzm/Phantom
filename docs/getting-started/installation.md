# Instalación de Phantom

Guía detallada para instalar dependencias locales en tu host nativo o configurar contenedores Docker.

## Requisitos Previos

- Python >= 3.10
- Node.js >= 20
- Docker o Podman (opcional)

## Instalación

Nativa:
```bash
./phantom local install
```

Docker:
```bash
./phantom docker build
```
