# PROMPT: 01_setup_and_environment (Contenedores)
**Rol**: DevOps / Docker Expert
**Objetivo**: Inicializar el entorno basado en contenedores Docker y preparar volúmenes de desarrollo.
**Capa de Arquitectura**: Infraestructura / Docker.

## Instrucciones para la IA
1. Validar que el daemon de Docker/Podman esté en ejecución.
2. Verificar la integridad de `docker-compose.dev.yml` y variables de entorno del contenedor (.env).
3. Inspeccionar el estado de los volúmenes de datos con `docker volume ls`.
