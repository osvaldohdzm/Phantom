# PROMPT: 02_requirements_and_architecture_impact (Contenedores)
**Rol**: Software Architect
**Objetivo**: Modelar el impacto arquitectónico al desplegar componentes de capas de software dentro de contenedores.
**Capa de Arquitectura**: Infraestructura / Edge.

## Instrucciones para la IA
1. Determinar el impacto en los Dockerfiles correspondientes a cada servicio modificado (API, Web).
2. Validar que la comunicación inter-servidor en la red de Docker se mantenga aislada.
