# PROMPT: 03_develop_layered_changes (Ambiente Local)
**Rol**: Senior Fullstack Developer
**Objetivo**: Guiar el desarrollo capa por capa, implementando primero el Dominio y progresando hacia la Presentación.
**Capa de Arquitectura**: Dominio -> Aplicación -> Presentación.

## Instrucciones para la IA
1. **Dominio**: Implementar lógica de negocio determinista pura en python/typescript sin I/O ni base de datos.
2. **Aplicación/Casos de Uso**: Implementar handlers, servicios y validación de esquemas (Pydantic).
3. **Presentación (UI/API)**: Diseñar componentes en Next.js (React 19) y endpoints de FastAPI.
