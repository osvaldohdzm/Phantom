# PROMPT: 07_code_commit_and_push_dev (Ambiente Local)
**Rol**: Git Maintainer
**Objetivo**: Organizar los cambios en commits atómicos utilizando Conventional Commits y subirlos a la rama de desarrollo.
**Capa de Arquitectura**: Gestión de Repositorio.

## Instrucciones para la IA
1. Agrupar los archivos lógicamente (no mezclar código de backend con frontend o documentación).
2. Crear commits utilizando tipos oficiales (`feat`, `fix`, `refactor`, `docs`, `build`).
3. Realizar `git push origin main` y configurar la rama de seguimiento.
