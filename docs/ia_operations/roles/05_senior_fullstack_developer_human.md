# ROL: Senior Fullstack Developer (Humano)

## 📌 Descripción General
El **Senior Fullstack Developer** es responsable de la construcción de las interfaces de usuario interactivas y la implementación de lógica de negocio en el backend del proyecto Phantom. Este rol se enfoca en resolver problemas complejos de rendimiento de interfaz (como el renderizado de gráficos de red con React Konva / Vis-Network) y estructurar endpoints de APIs robustos y seguros en FastAPI.

---

## 🛠️ Responsabilidades
1. **Desarrollo del Frontend**: Implementar páginas responsivas, componentes interactivos y layouts dinámicos en Next.js (utilizando App Router y React 19).
2. **Desarrollo del Backend**: Diseñar endpoints RESTful, validaciones con Pydantic y lógica de persistencia con SQLAlchemy.
3. **Optimización de Interfaz**: Asegurar que las interfaces complejas de visualización de vulnerabilidades y mapas de red carguen de manera fluida (micro-animaciones, renderizado condicional, optimización de bundles).
4. **Pruebas Unitarias y de Integración**: Escribir suites de pruebas completas tanto en el cliente (Jest/Testing Library) como en el servidor (Pytest).

---

## 🎓 Requisitos y Skillset
* **Experiencia**: +5 años en roles Fullstack utilizando Node.js/TypeScript y Python.
* **Frontend**: TypeScript, React 19 (App Router), Next.js, TailwindCSS/PostCSS, Konva.js/Vis-Network para grafos interactivos.
* **Backend**: Python 3.9+, FastAPI, SQLAlchemy, Alembic para migraciones, Redis para mensajería y caché.
* **Control de Versiones**: Manejo avanzado de Git, rebase interactivo y resolución de conflictos.

---

## 🤝 Protocolo de Colaboración con Agentes IA
* **Pair Programming**: Utiliza herramientas de codificación asistida por IA para acelerar la escritura de código repetitivo (ej: modelos de datos, endpoints CRUD básicos y esqueletos de componentes UI).
* **Refactorización guiada**: El desarrollador humano especifica la lógica del refactor y el agente IA la aplica a gran escala, permitiendo al desarrollador enfocarse en la revisión de bordes y la seguridad del código.
